# 📝 ทักษะ: การอัปเดตเอกสารและ GDD (Maintain Documentation)

## วัตถุประสงค์
ทักษะนี้มีไว้เพื่อให้แน่ใจว่าเอกสารการออกแบบเกม (`Game-Design-Document/Game_Design_Document.md`) และรายการงาน (`Game-Design-Document/task.md`) ตรงกับสิ่งที่ถูกพัฒนาในเกมจริงเสมอ หากมีการอัปเดตระบบ หรือเพิ่มฟีเจอร์ใดๆ ระบบจะทำการอัปเดตเอกสารตามไปทันที

## วิธีการทำงาน (Instructions)

1. **เช็คการเปลี่ยนแปลง (Review Changes):**
   - ทุกครั้งที่ฉัน (AI) เขียนโค้ดเพิ่มฟีเจอร์ใหม่, ปรับแต่งเกมเพลย์, หรือแก้ไขระบบในเกมเสร็จ ฉันจะต้องคำนึงถึงเอกสารเสมอ

2. **อัปเดต Game Design Document (Update GDD):**
   - ไปที่ไฟล์ `Game-Design-Document/Game_Design_Document.md`
   - เพิ่มหรือแก้ไขข้อมูลฟีเจอร์ใหม่ลงในหมวดหมู่ที่เหมาะสม (เช่น ฟีเจอร์หลัก, ระบบอาวุธ, หรือ Gamepasses)

3. **อัปเดตรายการงาน (Update Tasks):**
   - ไปที่ไฟล์ `Game-Design-Document/task.md`
   - ทำเครื่องหมาย `[x]` ในงานที่ทำเสร็จแล้ว
   - หากมีฟีเจอร์ใหม่ที่เพิ่งคิดได้และต้องทำต่อ ให้เพิ่มลงใน Task List ด้วย

4. **บันทึกความคืบหน้า (Update Progress):**
   - ไปที่ไฟล์ `Game-Design-Document/development_progress.md`
   - เขียนบันทึกประจำวันหรือหัวข้อว่าวันนี้ได้ทำระบบอะไรเสร็จไปบ้าง (เสมือนเป็นการเขียน Devlog)

5. **แจ้งให้ผู้ใช้ทราบ (Inform the User):**
   - หลังจากอัปเดตเอกสารเรียบร้อยแล้ว ให้สรุปให้ผู้ใช้ฟังด้วยว่า "ได้ทำการอัปเดตเอกสาร GDD, Task list และ Development Progress เพื่อให้สอดคล้องกับฟีเจอร์ล่าสุดเรียบร้อยแล้ว"
